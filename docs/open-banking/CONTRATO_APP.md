# Contrato del puente privado v1

Proveedor candidato: Enable Banking, solo AIS (lectura). URL del puente configurada por Vidal, HTTPS obligatorio en APK. Bearer token privado de emparejamiento (mínimo 32 caracteres); NO es contraseña bancaria ni clave del proveedor. JSON UTF-8; timeout; sin redirecciones HTTP automáticas; no guardar cuerpos en logs.

- `GET /v1/status` autenticado: `{ "provider":"enablebanking", "configured":true, "connected":false, "environment":"SANDBOX", "valid_until":null }`. `connected` significa sesión local autorizada no caducada, no verificación bancaria en vivo.
- `POST /v1/connect` autenticado, cuerpo `{}`: `{ "authorization_url":"https://auth.enablebanking.com/..." }`. Abrir navegador externo, nunca WebView de contraseña. El callback va al puente, no a un esquema Android. Al volver usar «Actualizar conexión».
- `GET /v1/accounts` autenticado: `{ "accounts":[{"key":"hex SHA256 identification_hash", "label":"Ibercaja · …1234", "currency":"EUR"}], "valid_until":"RFC3339" }`. key estable entre consentimientos, no UID efímero.
- `POST /v1/accounts/{key}/sync` autenticado, `{}`: `{ "account":{"key":"hex", "label":"Ibercaja · …1234", "currency":"EUR"}, "transactions":[{"id":"referencia bancaria estable", "date":"2026-10-20", "amount_cents":-1234, "description":"Compra", "value_date":null}], "fetched_at":"RFC3339", "date_from":"YYYY-MM-DD", "date_to":"YYYY-MM-DD", "complete":true }`. Solo BOOK y EUR. No se devuelve respuesta parcial: fallo de página, importe, fecha o referencia estable ausente aborta todo. Ventana inicial últimos 90 días, no histórico completo. El puente no persiste movimientos.
- `DELETE /v1/connection`: revoca sesión con proveedor, después borra estado local. Si falla la revocación, muestra error y conserva estado para reintentar. No borra movimientos ya importados.
- Errores JSON `{"error":"EXPIRED_SESSION", "message":"…texto seguro…"}`, estado 401 significa token inválido o sesión expirada según error. 503 PROVIDER_NOT_CONFIGURED. 502/422 respuesta no utilizable. 409 CONNECTION_EXISTS: revocar antes de reconectar (también si está caducada). 403 ACCOUNT_NOT_ALLOWED: cuenta no permitida. 429 RATE_LIMITED: esperar y reintentar. Nunca propagar cuerpos/error_description del banco.

APK: crear cuenta LOCAL NUEVA y separada por cada key: id `ob:` + key. Nunca mezclar automáticamente con la cuenta manual/CSV. Explicar esto antes de primera sincronización. Solo insertar nuevos por id determinista `ob:`+sha256(key+"|"+transaction.id). Preservar notas/categorías existentes; si un id existente cambia importe/fecha/concepto, abortar e informar (sin sobrescribir edición). Todo el lote validado antes de una transacción Room. Sin migración de esquema, `reference` se usa para la referencia bancaria, `batchId=null`, huella normal por cuenta/fecha/importe/concepto. `categoryId=categorize`, naturaleza normal revisable (transferencias propias manuales). Sync manual con app desbloqueada en esta tanda, sin background.

No afirmar «conectado al banco» con mocks. El servidor no se expone automáticamente. Alta proveedor, condiciones/coste, configuración HTTPS y SCA requieren participación de Vidal antes de live.
